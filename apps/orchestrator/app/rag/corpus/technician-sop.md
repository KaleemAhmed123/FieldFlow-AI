# Field Technician SOP

Source: https://support.example-fieldflow.test/sop

## Before travel
Confirm the required skill for the fault code and that the serving location holds the part. If stock is uncertain, reserve before dispatch to avoid a wasted visit.

## Safety
Isolate mains and discharge any high-voltage capacitor before board work. If a safety risk is reported on site, stop and escalate for human approval before proceeding.

## Completion
Run the self-test, record the fault code cleared, and close the work order to generate the service report.
